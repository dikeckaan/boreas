# Boreas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apple Silicon Mac'ler için menü çubuğundan yönetilen, sıcaklık eğrili fan profilleri sunan, ücretsiz ve açık kaynak fan kontrol uygulaması Boreas'ı yazmak.

**Architecture:** Tüm iş mantığı (SMC erişimi, sensörler, profiller, kontrol motoru, yardımcı servis çalışma zamanı) test edilebilir bir Swift paketi olan `BoreasCore`'dadır. `BoreasHelper` bu paketi kullanan, `SMAppService` ile kaydedilen ince bir root LaunchDaemon'dır ve XPC ile yalnızca imzası doğrulanmış `Boreas.app`'e hizmet eder. `Boreas.app` bir SwiftUI menü çubuğu ve pencere uygulamasıdır; servis yokken sensörleri yerelde salt okunur okur.

**Tech Stack:** Swift 6, SwiftUI, Swift Charts, IOKit (AppleSMC), IOHIDEventSystemClient (özel API, C başlığıyla), NSXPCConnection, SMAppService, XcodeGen, Xcode 27.2, notarytool, gh.

**Spec:** `docs/superpowers/specs/2026-11-08-boreas-design.md`

## Global Constraints

- Apple Silicon zorunlu. En düşük macOS: **15.0** (spec bunu builder'a bıraktı, bu planın kararı).
- Bundle ID'ler: uygulama `com.kaandikec.boreas`, servis `com.kaandikec.boreas.helper`, Mach servis adı `com.kaandikec.boreas.helper`.
- Bütün `xcodebuild` ve `swift` komutları `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` ile çalışır. `xcode-select` değiştirilmez.
- `.xcodeproj` depoya girmez; `project.yml` (XcodeGen) tek kaynaktır.
- Team ID depoya girmez: `Config/Signing.xcconfig` gitignore'dadır, `Config/Signing.xcconfig.example` commit'lenir.
- Uygulama ağa hiç çıkmaz. Telemetri, hesap, reklam ve kilitli özellik yoktur.
- Macs Fan Control'den kod, görsel, ad ya da metin kopyalanmaz.
- Arayüz metinleri Türkçe ve İngilizce, `Localizable.xcstrings` içinde.
- Lisans: MIT.
- Spec §7'deki güvenlik kuralları hiçbir ayarla kapatılamaz.
- Eğri devirleri, fanın `[min, max]` aralığında **0…1 oranı** olarak saklanır; arayüz rpm'e çevirerek gösterir. *(Plan kararı: yerleşik profillerin farklı fan aralıklarına sahip Mac'lerde de çalışması için.)*

## Review Focus

1. **SMC yazması kalıcı olur ama süreç ölür:** `boreasctl set` Ctrl-C ya da `kill` ile kesilirse fan elle modda kalmamalı. Task 2'de SIGINT/SIGTERM testi var.
2. **Uygulama penceresi kapalı, uygulama çalışıyor:** Kontrol döngüsü yine çalışmalı (döngü serviste). Bağlantı yalnızca uygulama süreci bittiğinde kopar. Task 6'da elle test edilir.
3. **Fan sayısı 0 olan Mac (MacBook Air):** Uygulama çökmeden yalnızca sensörleri göstermeli, servis kurulumunu istememeli. Task 2 (`FanController` boş liste) ve Task 7 (arayüz) testleri.
4. **Etkin profilin kullandığı sensör gizlenir ya da kaybolur:** Gizleme yalnızca görünümü etkiler, kural çalışmaya devam eder (motor tercihleri bilmez). Sensör kaybolursa kural geçersiz sayılır; fanın geçerli başka kuralı yoksa fan Otomatik'e döner. Task 5'te test edilir.
5. **Bozuk ya da eski ayar dosyası:** `settings.json` çözümlenemezse uygulama varsayılanlarla açılmalı ve bozuk dosyayı `settings.broken-<tarih>.json` olarak saklamalı. Task 7'de test edilir.

**Files:**

**Interfaces:**
- Produces:
  - `struct FourCC: Hashable, Sendable, ExpressibleByStringLiteral, CustomStringConvertible { let rawValue: UInt32; init(_ s: String) }`
  - `struct SMCParam` (yerleşim aşağıda), `MemoryLayout<SMCParam>.size == 80`
  - `enum SMCDataType: String { case flt = "flt ", ui8 = "ui8 ", ui16 = "ui16", ui32 = "ui32", sp78 = "sp78", fpe2 = "fpe2", flag = "flag" }`

  - `enum SMCError: Error, Equatable { case notFound(FourCC), ioFailure(Int32), notPrivileged, badSize }`
  - `final class FakeSMCClient: SMCClient` — `init(values: [FourCC: SMCValue])`, `var writes: [(FourCC, [UInt8])]`, `var failWrites: Bool`

**Files:**

**Interfaces:**
- Consumes: `Profile`, `Rule`, `Curve`, `SensorReading`, `FanInfo` (Task 2–4)
- Produces:
  - `enum FanMode: Codable, Equatable, Sendable { case auto; case fixed(rpm: Double); case profile }`
  - `enum FanCommand: Equatable, Sendable { case auto; case manual(rpm: Double) }`
  - `struct SafetyCeiling: Sendable { static let tripC = 100.0, releaseC = 90.0, windowSeconds = 5.0; mutating func update(readings: [SensorReading], now: Date) -> Bool /*tripped*/ }`
    - Girdi: `safety == true` okumaların en yükseği.
    - Hiç `safety` sensörü yoksa `cpu` ve `gpu` gruplarındaki `suspect == false` okumaların en yükseği kullanılır.
  - `struct EngineState: Sendable { var effectiveTemp: [UUID /*rule id*/: Double]; var lastRPM: [Int: Double]; var ceiling: SafetyCeiling; var lastTick: Date? }`

  - Sabitler: `rampUpRPMPerSecond = 600`, `rampDownRPMPerSecond = 300`.

Algoritma (sıra önemli):
1. Tavanı güncelle.
2. Her fan için:
   - `.auto` → tavan tetiklenmiş olsa bile `.auto` döner (Apple yönetir).
   - `.fixed(r)` → `r`, `[min, max]` aralığına sıkıştırılır.
   - `.profile` →
     1. Profil `nil` ya da `automatic` ise `.auto` döner.
     2. Her kural için kaynağın sıcaklığı alınır. Sensör yoksa ya da geçersizse kural atlanır.
     3. Histerezis uygulanır: `e` önceki etkin sıcaklık, `t` yeni ölçüm, `h` histerezis olmak üzere; `t > e` ise `e = t`, `t < e - h` ise `e = t + h`, aksi hâlde `e` değişmez.
     4. Kuralın devri: `min + curve.fraction(at: e) * (max - min)`. Fanın devri, kural devirlerinin en yükseğidir.
     5. Geçerli kural yoksa `.auto` döner.
     6. `releaseToAppleBelowMin` açıksa ve devir `<= min` ise `.auto` döner.
3. Tavan tetiklendiyse `.fixed` ve `.profile` modundaki fanlar `max` alır; yumuşatma atlanır.
4. Yumuşatma açıksa (yalnızca `.profile` modunda): bir önceki devirden bu yana geçen süreye `dt` denir. Devir en fazla `600 * dt` artabilir ve en fazla `300 * dt` azalabilir. İlk adımda yumuşatma uygulanmaz.
